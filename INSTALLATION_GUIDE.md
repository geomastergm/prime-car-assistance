# Brothers APK Installation Guide

## 📱 Installation Methods

### Method 1: Direct File Transfer
1. Connect phone to PC via USB
2. Copy APK files to phone's Download folder
3. Install from File Manager

### Method 2: Email Transfer  
1. Email APK files to yourself
2. Download on phone
3. Install from Downloads

### Method 3: Cloud Storage
1. Upload APK to Google Drive/OneDrive
2. Download on phone
3. Install

## 📂 APK File Locations

### Brothers (Client App)
**File:** Emergency-Road-Assistant-SIGNED.apk
**Location:** C:\Users\user\AndroidStudioProjects\Brothers\
**Size:** ~8MB
**For:** Customers requesting emergency services

### Brothers of Brothers (Provider App) 
**File:** app-debug.apk  
**Location:** C:\Users\user\AndroidStudioProjects\Brothers of brothers\app\build\outputs\apk\debug\
**For:** Service providers and admin

## 🔧 Installation Instructions

1. **Enable Unknown Sources:**
   - Settings → Security → Install unknown apps
   - Allow installation from File Manager

2. **Install Brothers.apk first** (Client app)
   - No login required - direct access to services

3. **Install BrothersProvider.apk** (Provider app)  
   - Use for registration: Fill application form
   - Admin login: azrikunikatuno / azrikunikatuno

## 🧪 Testing Scenario

1. **Client App:** Request emergency service
2. **Provider App:** Register as service provider  
3. **Admin Panel:** Approve provider applications
4. **Communication:** Test order flow between apps

## 📞 Support
If installation fails, check:
- Android version compatibility (min API 24)
- Storage space availability  
- Unknown sources permission enabled
